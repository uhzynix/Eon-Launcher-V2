## About

Eon Launcher V2 is the official launcher for Eon. This is an updated version of the old Eon launcher version. I took the existing project, redid it from scratch and improved it, with a completely new design, a rewritten interface, new features and a lot of bug fixes.

## Features

- **New interface:** a modern UI built with React and TypeScript, running inside a native WinUI 3 app
- **Build library:** install a build from the launcher or import one you already have. The launcher checks that the build is supported before launching
- **Home:** trailers, live player count and a one-click Play button
- **Leaderboard:** rankings by kills, wins and hype, with search
- **Item Shop:** browse items with rarity colors and a detail view
- **Server status:** see all servers with filters and pagination
- **Customization:** 20 color themes, a Liquid Glass effect and an animated background
- **Settings:** sound effects, minimize on launch, always on top and Bubble Builds
- **Quality of life:** remember me and auto-login, download notifications and a guided tour for new users
- **Discord Rich Presence**

## Building from source

> [!NOTE]
> Download the [Compiler](https://cdn.eonfn.dev/Compile%20Launcher.zip) to build the project yourself.

To build manually you need Windows 10 or 11, Visual Studio with the .NET desktop workload, and Node.js. Open `Eon Launcher.sln` and build. The web client in `WebClient/` is installed and compiled automatically during the build.
